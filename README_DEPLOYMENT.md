# Disease Prediction System

Machine-learning mini project for predicting a possible disease from selected symptoms.

## Models
- Decision Tree
- Random Forest
- Gaussian Naive Bayes

The project compares the models and uses the saved best model for prediction.

## Streamlit App
The web application is in `app.py`.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment
This repository can be deployed using Streamlit Community Cloud.
